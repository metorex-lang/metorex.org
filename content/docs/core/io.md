ruby/spec describes 118 methods in `core/io`, and Metorex implements 117 of them. The parameters are what `Method#parameters` answers under Metorex.

## IO::Buffer

- **`IO::Buffer#&`**: implemented, parameters `[[:req, :mask]]`. Generate a new buffer the same size as the source by applying the binary AND operation to the source, using the mask, repeating as necessary.
- **`IO::Buffer#^`**: implemented, parameters `[[:req, :mask]]`. Generate a new buffer the same size as the source by applying the binary XOR operation to the source, using the mask, repeating as necessary.
- **`IO::Buffer#and!`**: implemented, parameters `[[:req, :mask]]`. Modify the source buffer in place by applying the binary AND operation to the source, using the mask, repeating as necessary.
- **`IO::Buffer#bit_count`**: not implemented.
- **`IO::Buffer#empty?`**: implemented, parameters `[]`. If the buffer has 0 size: it is created by ::new with size 0, or with ::for from an empty string. [An example calling it](/examples/basics-stdout-redirection).
- **`IO::Buffer#external?`**: implemented, parameters `[]`. The buffer is *external* if it references the memory which is not allocated or mapped by the buffer itself.
- **`IO::Buffer.for`**: implemented, parameters `[[:req, :string]]`. Creates a zero-copy IO::Buffer from the given string's memory.
- **`IO::Buffer#free`**: implemented, parameters `[]`. If the buffer references memory, release it back to the operating system. [An example calling it](/examples/filesystem-io-writing-edges).
- **`IO::Buffer#initialize`**: implemented, parameters `[[:opt, :size], [:opt, :flags]]`. [An example calling it](/examples/errors-private-kernel-calls).
- **`IO::Buffer#internal?`**: implemented, parameters `[]`. If the buffer is *internal*, meaning it references memory allocated by the buffer itself.
- **`IO::Buffer#locked`**: implemented, parameters `[]`. Allows to process a buffer in exclusive way, for concurrency-safety. [An example calling it](/examples/c-extensions-c-mutexes).
- **`IO::Buffer#locked?`**: implemented, parameters `[]`. If the buffer is *locked*, meaning it is inside #locked block execution. [An example calling it](/examples/advanced-threads-leave-their-waits).
- **`IO::Buffer.map`**: implemented, parameters `[[:req, :file], [:opt, :size], [:opt, :offset], [:opt, :flags]]`. Create an IO::Buffer for reading from `file` by memory-mapping the file. [An example calling it](/examples/runtime-forked-popen).
- **`IO::Buffer#mapped?`**: implemented, parameters `[]`. If the buffer is *mapped*, meaning it references memory mapped by the buffer.
- **`IO::Buffer#not!`**: implemented, parameters `[]`. Modify the source buffer in place by applying the binary NOT operation to the source.
- **`IO::Buffer#null?`**: implemented, parameters `[]`. If the buffer was freed with #free, transferred with #transfer, or was never allocated in the first place.
- **`IO::Buffer#or!`**: implemented, parameters `[[:req, :mask]]`. Modify the source buffer in place by applying the binary OR operation to the source, using the mask, repeating as necessary.
- **`IO::Buffer#private?`**: implemented, parameters `[]`. If the buffer is *private*, meaning modifications to the buffer will not be replicated to the underlying file mapping.
- **`IO::Buffer#readonly?`**: implemented, parameters `[]`. If the buffer is *read only*, meaning the buffer cannot be modified using #set_value, #set_string or #copy and similar.
- **`IO::Buffer#resize`**: implemented, parameters `[[:req, :size]]`. Resizes a buffer to a `new_size` bytes, preserving its content. [An example calling it](/examples/c-extensions-c-strings).
- **`IO::Buffer#shared?`**: implemented, parameters `[]`. If the buffer is *shared*, meaning it references memory that can be shared with other processes (and thus might change without being modified locally).
- **`IO::Buffer.string`**: implemented, parameters `[[:req, :length]]`. Creates a new string of the given length and yields a zero-copy IO::Buffer instance to the block which uses the string as a source.
- **`IO::Buffer#transfer`**: implemented, parameters `[]`. Transfers ownership of the underlying memory to a new buffer, causing the current buffer to become uninitialized. [An example calling it](/examples/c-extensions-c-fibers).
- **`IO::Buffer#valid?`**: implemented, parameters `[]`. Returns whether the buffer buffer is accessible. [An example calling it](/examples/errors-syntax-error-syntax-suggest-reports).
- **`IO::Buffer#write`**: implemented, parameters `[[:req, :io], [:opt, :length], [:opt, :offset]]`. Write at least `length` bytes from the buffer starting at `offset`, into the `io`. [An example calling it](/examples/addresses-sockets-of-every-kind).

- **`IO::Buffer#|`**: implemented, parameters `[[:req, :mask]]`. Generate a new buffer the same size as the source by applying the binary OR operation to the source, using the mask, repeating as necessary.
