# metorex.org

Public site for the [Metorex](https://metorex.org) programming language.

## Local development

This web app is statically generated using [Blogin](https://blogin.dev).

### Install Blogin

```sh
brew tap gdonald/blogin
brew trust gdonald/blogin
brew install blogin
```

### Develop

```sh
cd metorex.org

blogin serve
```
